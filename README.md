# 办公文件查重

> 跨文件比对 Excel / Word 名单，重复只留一条 —— 留哪一条、每列写什么，由你决定。

[![Platform](https://img.shields.io/badge/Platform-Windows-0078D4?logo=windows&logoColor=white)](#)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Tests](https://img.shields.io/badge/tests-20%20passed-brightgreen.svg)](tests/run_tests.py)

一个本地运行的小工具：把手里多个 `.xlsx` / `.docx` 名单放进窗口，它会按你指定的列
（比如「姓名 + 手机号」）跨文件找出重复记录，并把结果另存为 `_已去重` 副本。
整个过程不联网、不上传，原文件一个字节都不改。

![界面](docs/gui_exe.png)

## 为什么不是“一键全自动去重”

因为真实数据里，同一个人的两条记录经常**互相矛盾**：A 文件写「销售部」，B 文件写「销售二部」；
A 表有电话没邮箱，B 表有邮箱没电话。粗暴地“保留第一条”往往保留的正好是错的那条。

所以这个工具的定位是**给你一张可编辑的合并单**：

- 跨文件判定重复，把每组记录摆在一起；
- 每组的「保留记录」可以换成任意一条（双击即可）；
- 每一列都是下拉框，装的是本组各文件出现过的值，选谁就是谁，也可以直接改字；
- 冲突列标红，并写出「另有：销售二部」——信息不会悄悄丢掉；
- 改坏了随时「还原本组」。

## 功能

**比对**

- 跨文件比对，或只在每个文件内部去重
- 多列组合成比对键（姓名 + 手机号 / 工号 / 身份证号……）
- 列名同义自动对齐：`电话 / 手机号 / 联系方式 / tel` 视为同一列，Excel 与 Word 表格也能对上
- Excel 多工作表逐个处理；Word 表格行与正文段落分别处理

**决策**

- 逐组改选保留记录、逐列挑值、任意字段手改
- 批量规则：保留「第一条 / 最后一条 / 字段最全的一条」；冲突取「第一个 / 最后一个 / 最长的值」
- 保留记录的空字段自动用重复行补上，并注明补自哪个文件第几行
- 其他文件独有的列可选择合并成新列（默认开启）
- 「只看冲突」筛选 + 关键字搜索 + 上一组/下一组，快速过几十组

**输出**

- 每个文件另存 `_文件名` 副本，**原文件不动**
- `查重报告.md`：每组留谁、每列最终值、来源（自动补值 / 手选 / 手填）、其他候选值
- `查重明细.csv`：可再导入 Excel 做二次核对
- 保留原有格式（表头样式、列宽、冻结窗格、边框、字体对齐）

## 快速开始

**免安装版（推荐）**

1. 下载 Release 里的 `办公文件查重-x.y.z-win64.zip`，解压到任意目录；
2. 双击 `办公文件查重.exe`；
3. 把文件拖进窗口 → ① 扫描并查重 → 确认每组的取值 → ② 生成去重文件。

**源码运行**

```bash
pip install openpyxl python-docx
# 可选：拖拽支持
pip install tkinterdnd2

python main.py          # 图形界面
```

**命令行**

```bash
python main.py a.xlsx b.docx --keys 姓名 手机号 --out 输出目录
python main.py 文件... --list-columns                  # 只看识别到哪些列
python main.py 文件... --keys 姓名 --scope within      # 只在各文件内部去重
python main.py 文件... --keys 姓名 --no-extra-columns  # 不新增其他文件独有的列
```

## 适用场景

- 多个部门各交一份客户/员工名单，需要合成干净的一份
- 活动报名表反复汇总，同一人报了多次
- 通讯录多版本合并，电话/邮箱散落在不同版本里
- 会议纪要里表格重复、正文段落重复

## 已知限制

- 只做了 Windows 打包（源码本身跨平台，macOS/Linux 可自行运行）
- 判定是「完全一致 + 列名同义」，不做模糊匹配：`阿里巴巴` 与 `阿里巴巴集团` 不会自动判为同一条
- 不支持 `.xls` / `.doc` / 加密文档，请先另存为新格式
- Word 只处理表格行与正文段落，页眉页脚、文本框、脚注不处理
- 新增 Word 表格列依赖 python-docx 1.1+
